# Detector
An initial attempt at COVID-19 Fake News Detection using the CoAID dataset.


## Installation
Simply copy the notebook to your jupyter environment and run the desired cells.

Please note that this repository does not include the glove-embeddings, which can be obtained from:
https://nlp.stanford.edu/projects/glove/

Please note that this repository does not include the necessary csv files, which can be obtained from the CoAID dataset:
https://github.com/cuilimeng/CoAID
